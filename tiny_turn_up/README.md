# Tiny Turn Up — Content Pack

Kids dance & movement songs (ages 3–7) built for **classroom brain breaks** and home dance parties.
Channel is **Made for Kids**, so comments/notifications/merch shelf are off — growth comes from
search titles, bright thumbnails, series playlists, compilations and steady uploads.

## Files
- `HOW_TO_MAKE_A_VIDEO.md` — **start here**: Suno song → `tinyturnup make` → `tinyturnup upload`
- `episodes/` — one folder per video (drop `song.mp3` in, videos come out in `build/`)
- `CHARACTERS.md` — the cast + style guide (use in EVERY image prompt)
- `songs/01-turkey-wobble.md` … `songs/04-snowman-shake.md` — lyrics with dance cues, music style, title, description, tags, thumbnail + scene prompts, Shorts
- `EXISTING_VIDEO_FIXES.md` — retitles for the 3 videos already live

## Rules for every video
- Title = what people search FIRST, channel name LAST.
- Open on a bright, colorful frame (it becomes the Shorts thumbnail).
- Long songs 2–3 min, start dancing within 5 seconds, no long intros.
- Same characters, same look, every time.
- Original songs and characters only — never use existing kids' characters or songs.
